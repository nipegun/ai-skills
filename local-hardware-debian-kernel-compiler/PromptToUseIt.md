# Tarea

Utiliza la skill `https://github.com/nipegun/ai-skills/local-hardware-debian-compiler/` para realizar la siguiente tarea:

Tarea:

"
Prepárame un kernel para el hardware desde el que te estás ejecutando.
Asegúrate de que incluya todos los controladores para el hardware de este equipo.
También ten en cuenta que es posible que algún hardware de este equipo no sea detectado por no tener módulos cargados que lo controlen. En ese caso, asegúrate de haber agotado todas las metodologías de detección de hardware, antes de preparar la lista de hadrware final.
Con el objetivo de hacer el kernel lo más pequeño y rápido posible, no incluyas en el kernel final todos los controladores que este hardware no tenga.
"
